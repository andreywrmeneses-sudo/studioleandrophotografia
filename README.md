# Leandro Visual Studio

Crie um site institucional premium, moderno, elegante e altamente visual para um fotógrafo profissional chamado “Studio Leandro Photografia”.

O objetivo do site é transmitir:
- Profissionalismo
- Sofisticação
- Exclusividade
- Qualidade fotográfica
- Modernidade
- Confiança
- Forte apelo visual
- Facilidade para o visitante entrar em contato e solicitar um orçamento

O site deve parecer um portfólio de fotógrafo profissional de alto padrão, e não um template genérico. A fotografia deve ser o elemento protagonista da experiência.

==================================================
2. DIREÇÃO ARTÍSTICA
==================================================

A estética deve combinar:

“Fotografia premium + editorial moderno + tecnologia + glassmorphism sofisticado”.

O site deve ter bastante espaço negativo, tipografia elegante, grandes fotografias e transições suaves.

Evite:
- Visual genérico de agência
- Excesso de cards
- Excesso de gradientes
- Excesso de neon
- Layout extremamente carregado
- Animações exageradas
- Muitos elementos competindo com as fotografias

O ciano deve aparecer como uma assinatura visual, e não dominar toda a interface.

As fotografias precisam ser sempre o elemento visual mais importante.

==================================================
3. LIQUID GLASS
==================================================

Todos os elementos interativos importantes devem utilizar uma linguagem visual “Liquid Glass”.

Aplicar em:
- Botões
- Menu
- Cards
- Pop-ups
- Elementos flutuantes
- Filtros
- Alguns controles das galerias

Características:
- Fundo translúcido
- backdrop blur
- Bordas semitransparentes
- Reflexos sutis
- Sombras suaves
- Glow ciano extremamente discreto
- Efeito de profundidade
- Hover com pequena mudança de brilho/transparência

O Liquid Glass deve parecer premium e sofisticado, nunca exagerado.
